# Community operations

These files are private working templates for the founder. They are not public website pages. Do not publish this folder, scrape contacts into it, or send any message from these drafts without founder review.

Nothing here is scheduled to send email. Outreach files are marked founder review required, never auto-send.

The monthly summary generator reads only records in the community store:

```bash
npm run community:impact
```

The same summary is on the private dashboard at `/admin/community`.
